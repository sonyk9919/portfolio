문의를 하나씩 답하는 대신, **왜 같은 질문이 반복되는지**를 먼저 봤습니다. 유형별로
분류해 보니 대부분 API 사용 예시가 부족해서 생기는 질문이었습니다.

API 기능별로 상세한 사용 예시와 직관적인 안내 텍스트를 담은 가이드를 작성해
배포했습니다. 그 결과 가이드가 커버하는 유형의 문의는 기술지원팀이 자체 해결하게 되어
개발팀 이관이 0건이 됐고, 매주 최대 8시간을 코어 제품 기능 고도화에 쓸 수 있게
됐습니다.
