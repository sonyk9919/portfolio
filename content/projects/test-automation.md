통합 테스트와 단위 테스트의 역할을 나눴습니다.

## 통합 테스트 — 핵심 사용자 시나리오

Cypress로 실제 사용자가 밟는 흐름을 그대로 재현했습니다. 상단바에서 주석 도구를
클릭하고, 생성 모드로 전환하고, 주석을 만들고, 크기와 위치를 바꾸고, 삭제하는 흐름을
주석 타입별 시나리오로 작성했습니다.

## 단위 테스트 — 데이터 무결성

Vitest로는 주석 편집 메서드를 실행했을 때 문서 메타데이터가 정확히 변경·반영되는지를
타입별로 독립 검증했습니다. UI 계층과 분리해서 보기 때문에, **화면에서는 정상으로
보이지만 저장된 데이터는 깨져 있는** 종류의 결함을 사전에 잡아낼 수 있습니다.
